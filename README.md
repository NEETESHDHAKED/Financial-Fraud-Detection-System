# 💳 Financial Fraud Detection System

Detect Fraud Financial Transactions using Machine Learning & Django.

## 🚀 Features
- Upload Transaction Data - CSV
- Fraud Detection with ML Model
- Real vs Fraud Transaction Check
- Admin Dashboard
- Fraud Transaction Alert

## 🛠️ Tech Stack
- Python
- Django
- Machine Learning - Scikit-learn
- Pandas / Numpy
- HTML / CSS / JavaScript
- SQLite

## 📦 How to Run
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
